Use cases

Work that needs to keep going.

ClawKraft is for teams that want real project outcomes from AI and compute they already control — with progress that survives worker changes and delivery that can be trusted.

Who it is for

Teams running real delivery on their own infrastructure.

These are product-shaped work patterns ClawKraft is designed to support. They describe platform behavior, not private customer deployments.

Product delivery

Multi-agent product work

Coordinate coding agents, reviewers, and browser workers across a repository so implementation, evidence, and review stay linked. Downstream work opens only when predecessors are accepted.

Research → execution

Long-running Programs

Turn an objective into dependency-aware work that can advance through research, implementation, and qualification stages while preserving decisions, evidence, and blocking findings.

Bring your own infra

Commission a host you control

Start from a VPS, workstation, or cloud host. Setup qualifies the capabilities the workload needs instead of forcing you to wire every runner and lifecycle path by hand.

External agents

Attach agents you already use

Connect compatible interactive, goal, coding, browser, or native workers. External agents can attach through the supported MCP endpoint without living inside the public website.

Failure recovery

Continue after a worker disappears

When a process, session, or provider is lost, durable checkpoints and handoff state let another worker resume instead of restarting the project from chat history.

Governed release

Changes that can be trusted

Separate producing a change from proving it. Inspect diffs, resolve findings, collect evidence, approve, merge, deploy, and verify with durable receipts along the path.

Work shapes

Different workers, one durable fabric.

ClawKraft coordinates multiple worker shapes without pretending they are interchangeable. Each can accept governed work, save progress, and hand off cleanly.

InteractiveChat workers that stay in the loop for decisions and correction.
Goal-orientedLong-running workers that advance a Program toward acceptance.
SpecializedCoding, browser, native, and external workers with focused jobs.
What stays private

Generic product. Private project intelligence.

ClawKraft ships generic capabilities. Customers create private workloads and project-specific Programs as they use it. Private execution context remains private to the customer environment and authorized control surfaces.

Not this

Not a prompt pile.

Loose prompts do not carry dependency structure, acceptance rules, evidence requirements, or recovery history. ClawKraft organizes work as Programs so execution can survive across workers, sessions, providers, and time.

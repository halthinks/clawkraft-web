What it does

Real project work, not loose prompts.

ClawKraft is an execution fabric that coordinates workers, infrastructure, source changes, proof, review, and delivery. It is designed so useful work can survive sessions, providers, process failures, and handoffs.

Persistent workers

Coordinate interactive agents, long-running goal workers, coding agents, browser agents, native workers, and external connected workers.

Isolated execution

Use worktrees, disposable CI, containers, databases, caches, persistent storage, warm environments, resource limits, and host-qualified isolation.

Durable handoffs

Assignments, checkpoints, receipts, leases, evidence, and review state remain durable so the next worker can continue instead of restarting from chat history.

Governed review

Carry changes through diff inspection, corrective work, tests, evidence, approval, and handoff before accepted state advances.

Governed deployment

Bind deployment to authorization, evidence, rollback behavior, production verification, and durable receipts.

Private workloads

Ship generic platform capabilities while keeping project-specific Programs, repositories, policies, credentials, and execution context private.

Durable execution

Progress should survive worker failure.

Worker A starts ↓ checkpoint ↓ Worker A disappears ↓ Worker B resumes ↓ evidence → review → completion

The durable model preserves assignment state, worker identity, leases, generations, checkpoints, receipts, evidence, review state, handoff state, and recovery history.

Use cases

Work that needs more than a single agent session.

ClawKraft is useful when the work has dependencies, multiple tools or workers, infrastructure requirements, failure modes, or a real delivery gate. The common thread is that progress needs to remain understandable and resumable after the current chat disappears.

BUILD

Multi-agent product delivery

Let different workers research, implement, review, test, correct, and deploy parts of the same product without losing the dependency graph between them.

R2E

Research → execution

Turn research, whitepapers, unfinished concepts, and projected use cases into reconciled program state, prioritized work, acceptance gates, and execution.

INFRA

Bring-your-own infrastructure

Commission a VPS, workstation, VM host, or other compatible machine into a governed execution fleet instead of hand-wiring a new runner each time.

PARALLEL

Disposable execution for parallel work

Give workers isolated CI and execution environments so parallel tasks can prove themselves without fighting over one mutable shared box.

CONNECT

Attach external agents through MCP

Give compatible clients a stable governed interface to the execution system while keeping private infrastructure topology and credentials behind the control plane.

RECOVER

Resume after worker or provider failure

Preserve checkpoints, leases, receipts, evidence, and assignment state so another worker can continue when a session, process, or provider disappears.

OPERATE

Operate a mixed AI workforce

Keep coding agents, browser agents, native workers, and long-running workers visible and controllable from one program-aware operating surface.

SECRETS

Broker credentials to the work that needs them

Keep secrets managed through governed vault and credential paths instead of spreading raw credentials across prompts, shells, and worker-local config.

DELIVER

Govern deployment and production proof

Require current evidence, authorization, rollback behavior, production verification, and durable receipts before delivery is treated as complete.

Disposable execution

Parallel work should not fight over one shared CI box.

Execution environments can be commissioned, assigned, checkpointed, handed off, returned, refreshed, replaced, or discarded. Proof remains bound to the work that produced it.

Failure and recovery

Failure should become state, not mystery.

ClawKraft is designed to reconcile worker death, stale leases, provider loss, CI failure, branch divergence, review invalidation, merge races, deployment failure, rollback, and stale or superseded work.

Governed delivery

Execution is only part of the job.

ClawKraft carries work through a delivery path that separates producing a change from proving, reviewing, accepting, merging, and deploying it.

Get started

Your onboarding front door.

ClawKraft begins where your infrastructure already is. Get Started routes you into Setup, where you commission an execution host and attach the workers and providers you already use.

Get Started Login Docs
Canonical journey: clawkraft.com → setup.clawkraft.dev → app.clawkraft.dev
What you need

Infrastructure and agents you already control.

You do not need to replace your stack. Bring a supported host and compatible workers; ClawKraft helps qualify the host and coordinate the workforce.

Bring

A machine you control

VPS, workstation, or cloud host. Setup commissions and qualifies the execution capabilities your workload needs.

Connect

Agents and providers you use

Interactive, goal, coding, browser, native, or external workers can join the workforce through supported interfaces.

Run

Programs with durable state

Objectives become dependency-aware work with checkpoints, evidence, review, and recovery history.

Operate

Mission Control on clawkraft.dev

Authenticated operators see program progress and governance controls on app.clawkraft.dev — not on this public site.

Onboarding path

Three surfaces. Clear handoffs.

Get Started leaves the public product surface and enters Setup. Existing operators can skip ahead with Login.

1. clawkraft.comLearn the product, trust posture, and onboarding path. No privileged controls.
2. setup.clawkraft.devCommission and qualify an execution host. Begin at Get Started.
3. app.clawkraft.devOperate programs and workforce in Mission Control. Existing users use Login.
